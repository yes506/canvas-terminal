Architecture report — resilience-recovery

Language: typescript · Last completed phase: validated

Project plan

Goal: 슬립/백그라운드 복귀 후 '헤더만 남고 콘텐츠 사망'하는 치명 버그를 사인확정→자동복구→압박완화 3층으로 구조 해소. 진단 미확정(A WebContent사망 vs B JS fatal)을 존중해 모든 seam을 설계하되 구현은 증거-게이팅.

In-scope

  • #1 RootErrorBoundary (main.tsx 최상위 경계 = 사인 분기기; PaneErrorBoundary 패턴 재사용)
  • #2 Instrumentation: heartbeat + WebContent-death 감지 + 메모리/컨텍스트 watermark
  • #3 LosslessRecovery: topology 영속/복원 + 살아있는 Rust PTY 재attach 오케스트레이션
  • #4 PressureMitigation: WebGL 컨텍스트 상한 + 스크롤백 상한 (비가시 탭 렌더 일시정지는 기존 IO 활용)
  • Rust 계약 문서화: reattach_pty / persist_topology / load_topology / (옵션)webview-death 훅

Out-of-scope

  • 메서드 바디 구현 (다운스트림 implementer 소관)
  • Rust PTY-reattach 스켈레톤 코드 생성 (계약 문서화만; 필요 시 별도 planner run)
  • 실제 OS jetsam 확진 (런타임 계측 수집은 #2 구현 후 운영 활동)
  • 멀티윈도우 / 비-macOS 플랫폼 분기

Constraints

  • URL-scheme THREE-way invariant / localfile 토큰 규칙 등 기존 불변식 불침범
  • 공유메모리 dir은 PID 기반(memory.rs:21); reload는 PID 불변이라 dir·PTY 보존 — 설계 전제
  • 정상종료(Destroyed)→clear_memory_dir 능동삭제 경로 유지(복구는 Destroyed 미발화 경로 가정)
  • 버전 하드코딩 금지; tsc --noEmit 통과; 전 메서드 9-field docstring

Success criteria

  • 4개 권고의 모든 cross-boundary seam이 인터페이스/계약으로 명시됨
  • 구현 단계 게이트가 설계에 박혀 있음: #1+#2 우선 → 증거 → #3/#4 (shouldRecover 게이트)
  • RootErrorBoundary가 사인 분기기로 동작(잡힘=B, 미잡힘=A)하는 계약 정의
  • 복구 경로 무손실: topology 복원 + 기존 PTY 재attach 계약 정의
  • architecture.html + architecture.mmd 산출, tsc 통과(달성: TSC_OK)

Open questions

  • Q1(확정: heartbeat 우선) WebContent 사망 1차 감지 메커니즘 — Rust webview delegate 훅은 계약만
  • Q2(확정: in-place reload 1차) 복구 액션 — recreate-webview는 폴백 계약으로 보유
  • Q3(확정: 신규 경량 IPC) topology 영속 위치 — persist_topology/load_topology
  • Q4(확정: 신규 reattach_pty) 출력 버퍼 재생 범위 — ReplayBudget.maxBytes로 상한
  • 잔여: #3/#4 구현 착수 전 #2 런타임 증거로 사인(A/B) 확정 필요

Package layout

  • src/components/IResilienceBoundary.ts (#1 boundary contract)
  • src/stores/IResilienceStore.ts (FSM store contract)
  • src/lib/resilience/ (#2 heartbeat/watermark/deathDetector, #3 topology/reattach/orchestrator, #4 webglBudget/scrollback)
  • src-tauri/src/commands/ (Rust 계약: reattach_pty/persist_topology/load_topology — 문서화만)

All interfaces are expanded by default so the reviewer can spot-check the 9-field docstrings without scrolling through a chat log.

IResilienceBoundary (src/components, cohesion: #1 Root error-boundary = sign discriminator (caught ⇒ js-fatal/B; silent blank ⇒ WebContent death/A))
  • onTopLevelError fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Capture a top-level throw as sign 'js-fatal'; marks boundaryCaught for the detector. Must never itself throw.
  • renderFallback fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Render the recovery fallback UI (status + retry control) from a RecoveryView; retry delegates to the orchestrator.
IHeartbeat (src/lib/resilience, cohesion: #2 Liveness ticker — last-beat timestamp distinguishes 'backgrounded' from 'WebContent died')
  • start fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Begin emitting liveness ticks; idempotent while running.
  • recordTick fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Record that the render loop reached this instant alive (writes last-beat).
  • lastBeatAt fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Report epoch-ms of the last tick; non-decreasing within one live JS context.
  • stop fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Stop ticking and release the timer; idempotent.
IWatermarkSampler (src/lib/resilience, cohesion: #2 Resource-pressure observer — memory/GPU/tab watermarks that correlate with jettison)
  • sample fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Capture a point-in-time ResourceWatermark; missing APIs degrade to null fields, not throws.
  • log fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Persist/emit a watermark; logging failures swallowed so instrumentation never destabilizes the app.
IDeathDetector (src/lib/resilience, cohesion: #2 Sign inference — turns liveness gap + boundary evidence into RootCauseSign (the A/B discriminator))
  • onVisibilityRegained fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Analyze the heartbeat gap on visibility regain → LivenessVerdict (gapMs, suspectDeath).
  • classifySign fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Combine verdict + boundaryCaught into a SignClassification; ambiguity ⇒ 'unknown' low-confidence, not a throw.
ITopologySnapshot (src/lib/resilience, cohesion: #3 Topology (de)serializer — the seam making webview reload non-destructive (front-end topology is memory-only today))
  • capture fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Serialize live terminal+collaborator topology to a versioned TopologySnapshot (best-effort per-leaf cwd).
  • restore fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Rebuild stores from a snapshot; per-leaf failures collected into failedSessions; throws only on unsupported version.
IPtyReattachClient (src/lib/resilience, cohesion: #3 Front-end client for the Rust reattach_pty contract — rebinds xterm to PTYs that survived reload)
  • reattach fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Rebind one session to its surviving Rust PTY via reattach_pty IPC; dead PTY ⇒ alive:false (not a throw).
  • replayInto fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Write a PTY's replay buffer into its xterm and scroll to bottom; disposed-terminal writes guarded.
IRecoveryOrchestrator (src/lib/resilience, cohesion: #3 Recovery control loop — only seam allowed to trigger reload; hosts the staged-implementation evidence gate)
  • shouldRecover fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Gate whether recovery runs for a sign; while the #3 evidence gate is closed, returns proceed:false regardless of sign.
  • recover fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Run capture→persist→reload→restore→reattach→verify; per-session losses surface in lostSessions; abort ⇒ failed, not throw.
  • abort fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Abort an in-flight recovery and settle to a safe state; idempotent; restored panes left intact.
IWebglContextBudget (src/lib/resilience, cohesion: #4 WebGL context cap allocator — bounds simultaneous xterm WebGL contexts (over-allocation feeds jettison))
  • acquire fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Request a WebGL slot for a main terminal; denial ⇒ granted:false and caller uses the DOM renderer.
  • release fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Return a granted slot to the pool; idempotent; tolerant of unknown sessions.
  • activeCount fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Report live granted contexts (0..cap); never negative.
IScrollbackPolicy (src/lib/resilience, cohesion: #4 Per-terminal scrollback cap — bounds unbounded buffer growth across many tabs/mini-panes)
  • limitFor fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Resolve the scrollback line cap for a TerminalKind; 'mini' cap ≤ 'main' cap.
  • enforce fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Apply the resolved cap to a live xterm (sets scrollback option); idempotent; disposed terminals skipped.
IResilienceStore (src/stores, cohesion: #1/#2/#3 Recovery FSM + last-observation store (Zustand) — single source of truth for phase/sign/watermark)
  • recordSign fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Record the classified sign for the current incident; notifies subscribers.
  • transition fields: Responsibility, Pipeline-position, Inputs, Outputs, Side-effects, Preconditions, Postconditions, Failure-modes, Collaborators 
    Move the FSM to a new phase; illegal transitions coerced to 'failed'; increments attempts on 'recovering'.

    Return an immutable ResilienceState snapshot; mutating it does not affect the store.
