peer-context-mirror

Language: rust+typescript · Last completed phase: artifacts_emitted

Project plan

Goal: Surface each collaborator agent's externally observable working context (everything its CLI tool persists to disk + PTY-visible output) into the shared collab-memory layer, normalized to a canonical NormalizedTurn record. Deliver an extensible TranscriptAdapter trait as the durable contract.

In-scope

  • Watch transcript files for: Claude Code, Codex CLI, Gemini CLI
  • Extensible TranscriptAdapter trait; adding adapter for an EXISTING registered tool = one new file
  • Real-time tailing via Rust notify/fsevents with inode+offset resume state
  • NormalizedTurn canonical record with normalized_schema_version, source_tool, source_tool_version (nullable), adapter_version, agent_handle, ts_iso8601, ts_source, role, text_visible, turn_index, source_offset
  • Per-adapter content-block inclusion table; default EXCLUDE: thinking, tool_use, tool_result, image, redacted_thinking, system
  • Agent-identity pre-registration: reserveAgentHandle(collabSessionId, tool) → {handle, reservationId} with rollback on spawn failure
  • Env injection at spawn via shared apply_extra_env helper; passed for both spawn_process and spawn_shell paths
  • Shell fallback uses exec <tool.command> so shell PID becomes CLI process
  • Per-agent OPT-IN publish (default OFF) with persistent indicator
  • PeerContextPanel: two-call concat reader (active + last archive ≤16MB rolling) with visual fence and truncation footer

Out-of-scope

  • In-process / model-internal state (KV cache, hidden activations, system prompt, mid-turn scratch, swallowed tool results, prompt cache)
  • Bidirectional sync (one-way only)
  • AI summarization / digesting (snapshot direction parked)
  • Re-mirroring peer mirror files (recursion guard)
  • Auto-injection of peer transcripts into reader agent prompts
  • Automatic secret redaction (fenced UI + warning posture instead)
  • copilot_cli in v1 (declared in ToolId but no adapter)
  • Adding brand-new tools to the collaborator registry
  • Aider as a production adapter (lives only at src-tauri/tests/transcript_adapter_contract.rs as a test-only fixture)
  • Reading older rolled archives via UI beyond active+last (deferred — user inspects files directly)

Constraints

  • FS-gate split: src-tauri/src/commands/fs_safety/ shared primitives; memory.rs public API unchanged; transcripts/fs_gate.rs new external-root gate
  • Mirrored content is UNTRUSTED input — visual fence, path-only breadcrumb, no auto-inject
  • Adapter schemas best-effort; unknown native fields dropped; source_tool_version nullable, adapter_version always present
  • Active mirror file capped at 8MB; rotation protocol: scan-dir for next N, fsync, rename old, atomic-rename new active. Crash recovery: no auto-promote
  • .state.json records (path, inode, byte_offset, last_turn_index); inode mismatch on restart resets offset to 0
  • PID→open-FD binding via lsof / /proc/<pid>/fd is PRIMARY, one-time at session-bind, cached; never inside tailer loop
  • agent_handle is CT-injected at normalize-time; source transcripts have no such field
  • ts_iso8601 prefers source-tool timestamp; ts_source records origin
  • Empty text_visible after content-block filter is SKIPPED; turn_index still increments
  • CT_AGENT_ID = bare handle ('claude3'); CT_COLLAB_SESSION_ID = collabSessionId (distinct from process-scoped session-<pid>)
  • Watcher lifecycle: single TranscriptWatcher in Tauri State<>; lazy start; ref-count; dropped on WindowEvent::Destroyed + RunEvent::Exit; clear_stale_sessions is startup-only and unrelated
  • No automatic secret redaction — opt-in publish + visual fence + warning banner + publishing indicator
  • Transcript root paths pinned per adapter (Claude/Codex/Gemini)

Success criteria

  • TranscriptAdapter trait + 3 production impls + 1 test-only fixture (Aider) compile clean
  • Adding a transcript adapter for an EXISTING registered tool requires zero changes outside adapters/<tool>.rs
  • CI: `git grep -l -i aider -- 'src-tauri/src/**' 'src/**'` outputs 0 lines
  • memory.rs FS-gate test suite passes UNCHANGED after fs_safety/ extraction
  • Adversarial path corpus (traversal, symlink-out, /private aliasing, env-var injection, NUL byte, wrong-root, case-folding) passes for both memory.rs and transcripts/fs_gate.rs via shared fs_safety/
  • P95 tailing latency < 2s under nominal load
  • PeerContextPanel renders active + last archive (≤16MB) with visual fence; publishing indicator visible; truncation footer when archives beyond window exist
  • Default visibility OFF on session start
  • Restart-resume: tailer picks up from (path, inode, offset); stale inode resets
  • Rotation crash recovery: archive present + active absent → no auto-promote; next write creates fresh active
  • Zero leaked FSEvents callbacks after Tauri exit (verifiable with fs_usage during dev hot-reload)

Open questions

  • PeerContextPanel placement: tab / modal / inline (Phase 4 UX)
  • Long-term retention of rolled archives (default: session-lifetime)
  • K6 exec shell-fallback PTY-lifetime side-effect — verify no UX regression in Phase 2
