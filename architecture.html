browser-localfile

Language: rust · Last completed phase: validated

Project plan

Goal: Let the user open a local file (HTML, PDF, image, plaintext) in any browser-drawer tab via a native file picker, without lifting the v1 deny on `file:` URLs. A new `localfile://<22-char-token>` custom URI scheme streams ONLY user-picked files, tab-scoped at the protocol handler.

In-scope

  • F1 — 'Open File' affordance in the browser-drawer chrome (placement inside NavControls as the leftmost icon).
  • F2 — Native file picker via tauri-plugin-dialog (open({ multiple: false, directory: false })).
  • F3 — New Tauri command mint_localfile_token(tabId, path) → token.
  • F4 — New LocalFileTokenRegistry state: Mutex<HashMap<Token, TokenEntry>>.
  • F5 — App-level custom URI scheme 'localfile' registered via register_asynchronous_uri_scheme_protocol.
  • F6 — Protocol handler enforces tab-scoping by reading UriSchemeContext::webview_label() and comparing to entry.tab_id.
  • F7 — Strict response headers: Content-Type, Content-Length, CSP with sandbox, X-Content-Type-Options nosniff, Referrer-Policy no-referrer, MIME-class-driven Content-Disposition.
  • F8 — Token revocation: destroy_browser_tab → revoke_for_tab; navigate to non-localfile → revoke_for_tab; destroy_all + Exit/Destroyed → clear.
  • F9 — Frontend classifier (urlScheme.ts) allows strictly-shaped localfile://<22-char-token>; arbitrary localfile: typed input remains denied.
  • F10 — Backend validate_browser_url mirrors F9 so existing navigate_browser_tab path accepts well-formed token URLs.

Out-of-scope

  • Save-as / download endpoint.
  • Drag-and-drop file → tab.
  • Directory open or directory listing.
  • Watching the picked file for changes (no inotify / fsevent).
  • Windows / Linux platform support (the per-webview-protocol assumption in the original prompt was disproven; we use app-level registration + UriSchemeContext::webview_label for tab-scoping — portable in principle but needs per-OS validation in a future cycle).
  • OS passkey / WebAuthn work (separate question, separate plan).

Constraints

  • C1 — Defense-in-depth invariant from browser.rs:4-6 holds: every change to the ALLOW/FILTER/DENY matrix in validate_browser_url must land synchronously with the matching classifyScheme update in urlScheme.ts. This change extends that to a THREE-way invariant including commands::localfile::validate_localfile_url_shape.
  • C2 — `file:` URLs remain DENIED. This change adds a SEPARATE scheme.
  • C3 — No new entitlements. com.apple.security.files.user-selected.read-write in entitlements.plist already covers user-picked file reads.
  • C4 — No changes to MAIN window CSP in tauri.conf.json — main window doesn't load localfile://. The custom protocol response's own CSP (F7) is what matters.
  • C5 — Tokens are single-tab-scoped, NOT one-shot. They must survive reloads, sub-resource fetches, and re-navigation within the same tab's lifetime.
  • C6 — No TTL in v1. Tab-lifetime scoping (F8) is sufficient.

Success criteria

  • S1 — User clicks Open File → dialog → picks PDF → active tab renders the PDF inline.
  • S2 — Same flow with .html, .png, .txt — all render appropriately.
  • S3 — Unit tests: validate_browser_url accepts a well-formed localfile://<22-char-token> string and rejects malformed variants; classifyScheme mirrors.
  • S4 — Manual cross-tab test: a token minted for tab_A cannot be served if presented from tab_B's webview (returns 404).
  • S5 — Closing a tab purges its tokens (verifiable via instrumentation or test command).
  • S6 — cargo check passes on the Phase 5 skeleton.
  • S7 — cargo test passes on existing browser.rs::tests plus new shape-validation tests.

Open questions

  • Q1 — async vs sync protocol handler. RECOMMENDATION: async (register_asynchronous_uri_scheme_protocol) so tokio::fs::read does not block the protocol thread. Implementer to confirm in body.
  • Q2 — 256 MiB size cap; >cap returns 413 with empty body. Streaming is v2.
  • Q3 — CSP sandbox interaction with macOS PDFKit inline rendering. Initial recommendation: keep sandbox; PDFKit on macOS is the OS's built-in viewer (no JS) so sandbox should be safe. Revisit if a real breakage surfaces.
  • Q4 — Deny-prefix list initial set: /System, /private/var/db, /Library/Keychains, ~/Library/Keychains, ~/.ssh, ~/Library/Application Support, ~/Library/Cookies, /etc, /var, /usr (with /usr/local excepted). Implementer to finalize.
  • Q5 — Mint-error surfacing via the existing per-tab error field on BrowserStore (same channel as URL-validation errors today).
  • Q6 — Address-bar typed localfile://<token> is allowed at the classifier level (mirrors backend) but expected to see zero legitimate use; the value is paste-from-clipboard / programmatic re-set within a tab's lifetime.

Interfaces & method docstrings

All interfaces are expanded by default so the reviewer can spot-check the 9-field docstrings without scrolling through a chat log.

LocalFileTokenStore (src-tauri/src/state.rs, cohesion: state + lifecycle + failure-domain (single Mutex<HashMap>, app-lifetime, lock-poisoning all callers share))
  • mint fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Atomically mint a fresh token, bind it to (tab_id, canonical_path, mime), store the entry, return the token. Token generation (16 bytes getrandom + URL-safe-base64 + collision check) is an internal impl detail under the same lock scope as the insert; not surfaced as a cross-interface collaborator.
  • lookup fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Read-only lookup with tab-scope enforcement. Returns Some(entry) on hit AND tab match, None on miss OR tab mismatch (404-equivalent — caller cannot distinguish, deliberate). Mutex poison swallowed to None.
  • revoke_for_tab fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Drop every entry whose tab_id matches. Best-effort: Mutex poison swallowed to 0 (preferring partial cleanup over leak). Idempotent. Called from commands::browser destroy and navigate-away hooks.
  • clear fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Drain every entry. Used at app teardown (destroy_all_browser_tabs_impl, WindowEvent::Destroyed, RunEvent::Exit). Best-effort idempotent.
  • new (LocalFileTokenRegistry::new) fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Construct an empty registry. Called once in lib.rs::run() before .manage().
commands::localfile (src-tauri/src/commands/localfile.rs, cohesion: lifecycle (mint pipeline 1→2→3→4 + serve pipeline 6→fs→7) + collaboration boundary (both pipelines call LocalFileTokenStore))
  • validate_picked_path fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Canonicalize, reject directories/symlinks/sockets/FIFOs/devices, reject paths under v1 deny-prefix list. Returns the canonical PathBuf. Terminal validation step (no downstream collaborators).
  • classify_mime fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Determine MIME from canonical path's extension; application/octet-stream fallback. Pure; guaranteed no CR/LF/control bytes in output (header-safe).
  • build_localfile_response fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Compose http::Response<Vec<u8>> with full v1 security-header set (CSP+sandbox, nosniff, no-referrer, MIME-class-driven Disposition).
  • validate_localfile_url_shape fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Single source of truth for `localfile://<token>` shape gate. Used by extended validate_browser_url. Strict 22-char base64-url; rejects everything else.
  • mint_localfile_token (#[tauri::command]) fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Tauri command entry — orchestrates validate_picked_path → classify_mime → LocalFileTokenStore::mint. Returns token to frontend.
  • localfile_protocol_handler fields: responsibility, pipeline_position, inputs, outputs, side_effects, preconditions, postconditions, failure_modes, collaborators 
    Async URI-scheme handler. Parses token + reads UriSchemeContext::webview_label, strips `browser-tab-` prefix, LocalFileTokenStore::lookup (tab-scoped), tokio::fs::read, build_localfile_response, responder.respond.
